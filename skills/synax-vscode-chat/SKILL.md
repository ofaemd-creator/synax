# SYNAX VS Code Chat & 3D Agent Office Extension (`synax-vscode-chat`)

Use this skill to package and install the `.vsix` extension or launch the VS Code 3D Agent Office & Turkish LLM Studio.

## Commands
```bash
# Install into local Visual Studio Code & Antigravity IDE
"/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code" --install-extension /Users/o.farukaydin/.gemini/antigravity/scratch/synax/editors/vscode-synax/synax-vscode-chat-2.1.0.vsix --force
"/Applications/Antigravity IDE.app/Contents/Resources/app/bin/antigravity-ide" --install-extension /Users/o.farukaydin/.gemini/antigravity/scratch/synax/editors/vscode-synax/synax-vscode-chat-2.1.0.vsix --force
```
