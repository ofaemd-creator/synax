# SYNAX 3D Agent Office — Claude Code, OpenAI Codex & Antigravity Instructions

This repository is powered by **SYNAX 3D Agent Office (`v2.5.0`)** and **SYNAX-LLM (`SYNAX-LLM-TR-v2.5`)**.

## Active MCP Tools (Claude Code & OpenAI Codex)
- `synax_office_multitask(prompt)` — Executes all 6 autonomous office agents in parallel and generates real `.sx`, `.py`, `.c` (ARM64 NEON / AVX2 / Q16.16 MCU), `0-ULP` proof, and `SHA-256` handoff capsule files.
- `synax_llm_chat_tr(message)` — Converses in natural Turkish with the trained `SYNAX-LLM` language model.
- `synax_token_shield_compress(content)` — Saves 75%–92% tokens via AST skeletonization & RLE deduplication.
- `synax_context_vault_handoff(task_summary)` — Seals a `<180 token` `SHA-256` memory capsule between Claude Code and OpenAI Codex.
